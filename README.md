# Mousos

Mousos is a web os with the focus of creating a unique UX experience centered around using your mouse.

## Controls

| Action        | Key                               |
|---------------|-----------------------------------|
| App Launcher  | CTRL + RIGHT CLICK                |
| Move Window   | ALT + LEFT CLICK (hold and move)  |
| Resize Window | ALT + RIGHT CLICK (hold and move) |

## Build Instructions

To build Mousos you have to install the required dependencies using `npm install` and build the project using `npm run build`.

The default build output directory is `./dist`.
